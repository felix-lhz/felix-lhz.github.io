# Huaizhi Liao · Academic Homepage

Public website: https://felix-lhz.github.io/

## Maintenance / 维护

The homepage is a single static file, `index.html`, containing both the page content and its responsive CSS. No dependencies, build tools, or external fonts are required.

- Edit `index.html` to update your profile, research interests, or contact information. Update the page description in the `<head>` when changing your profile.
- Keep email addresses and their `mailto:` links consistent.
- Preview locally by opening `index.html` in a browser.
- Commit changes to `main`. GitHub Pages publishes from the root of the `main` branch.
- Keep `.nojekyll` so GitHub Pages serves these files directly.

主页内容和样式均在 `index.html` 中。修改后提交到 `main` 分支即可自动更新，无需安装工具。三个邮箱均为公开联系方式；维护时请同时修改可见文本和对应的 `mailto:` 链接。

## GitHub Pages settings

In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**. The site uses the default GitHub Pages HTTPS domain.
