# Huaizhi Liao | Academic Homepage

Public website: https://felix-lhz.github.io/

## Maintenance

The homepage is a static file, `index.html`, containing the page content and responsive CSS. No dependencies, build tools, external fonts, or JavaScript are required.

- Edit `index.html` to update the profile, publications, or contact information.
- Keep the website entirely in English.
- Keep displayed email addresses consistent with their `mailto:` links.
- Add publication citations under `publications/`. Update both the on-page BibTeX and the downloadable `.bib` file together.
- List only publications with information approved for public display. Do not add unpublished-paper placeholders.
- Preview locally by opening `index.html` in a browser.
- Commit changes to `main`. GitHub Pages publishes from the root of that branch.
- Keep `.nojekyll` so GitHub Pages serves the files directly.

## GitHub Pages settings

In **Settings > Pages**, use **Deploy from a branch**, branch **main**, folder **/ (root)**. The website uses the default GitHub Pages HTTPS domain.
